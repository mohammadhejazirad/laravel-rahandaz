## اتصال از پنل
از «حساب‌های گیت» تنظیمات یک GitHub App را ثبت کنید: Client ID، Client Secret و نام برنامه در نشانی GitHub. Callback URL و Setup URL را برابر نشانی نمایش‌داده‌شده در پنل قرار دهید. گزینهٔ Request user authorization during installation خاموش و Redirect on update روشن باشد. فقط مجوزهای Repository contents: Read-only و Metadata: Read-only لازم‌اند؛ برنامه با مجوز نوشتن پذیرفته نمی‌شود.

## انتخاب مخزن‌های مجاز
روی «اتصال حساب در GitHub» بزنید. هنگام نصب برنامه، Only select repositories را انتخاب و مخزن‌های دلخواه را مشخص کنید. پس از بازگشت و تأیید هویت، دریافت فهرست در صف انجام می‌شود. در صفحهٔ حساب، مخزن‌های قابل استفاده در پنل را انتخاب و دسترسی‌های هر صفحه را ذخیره کنید. مخزن جدید خودکار مجاز نمی‌شود. انتخاب پنل و مجوز نصب GitHub دو کنترل مستقل‌اند.

## پیگیری و بازیابی
تاریخچهٔ حساب شروع دریافت، صفحه‌های API، نتیجه و تغییر دسترسی مخزن‌ها را همراه تاریخ و ساعت نشان می‌دهد. در شکست، «دریافت دوبارهٔ مخزن‌ها» را بزنید. worker صف control باید فعال باشد. فهرست ناقص جای فهرست قبلی ذخیره نمی‌شود. پس از همگام‌سازی موفق، مخزن حذف‌شده از مجوز سرویس در پنل هم غیرفعال می‌شود. مجوز منقضی با refresh token تمدید می‌شود؛ در شکست، اتصال مجدد لازم است.

## قطع اتصال
«قطع دسترسی پنل» انتخاب‌های مخزن را غیرفعال و اعتبارنامهٔ محلی را باطل می‌کند؛ repository، پروژه یا release حذف نمی‌شود. برای حذف مجوز واقعی، «مدیریت مجوز در سرویس» را باز و نصب برنامه را در GitHub حذف یا محدود کنید. اتصال مجدد از صفحهٔ حساب‌های گیت ممکن است.

## محدودیت فعلی
این بخش حساب و فهرست دسترسی مخزن را مدیریت می‌کند. اتصال منبع به پروژه از فرم ZIP، ثبت webhook و فعال‌کردن auto deploy را انجام نمی‌دهد. جریان OAuth با API ساختگی آزموده شده؛ تأیید زنده با GitHub App واقعی همچنان لازم است. توکن، راز برنامه یا پاسخ خام سرویس را در screenshot و گزارش عمومی منتشر نکنید.
