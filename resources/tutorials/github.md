## اتصال از پنل
از «حساب‌های گیت» روی «افزودن حساب» و GitHub بزنید. اگر این نصب هنوز برنامه ندارد، «اتصال با تأیید در GitHub» را انتخاب کنید. در صفحهٔ بعد GitHub را باز و ساخت برنامه را تأیید کنید؛ نیازی به کپی‌کردن Client ID یا Secret نیست. راه‌انداز اطلاعات اتصال را مستقیم دریافت و رمزگذاری می‌کند، سپس صفحهٔ نصب و انتخاب مخزن‌ها باز می‌شود. برنامهٔ خودکار خصوصی و متعلق به حساب سازنده است.

برای برنامهٔ موجود یا سازمانی، در «تنظیمات پیشرفتهٔ اتصال با مرورگر» Client ID، Client Secret و نام برنامه را ثبت کنید. Callback و Setup URL برابر نشانی نمایش‌داده‌شده باشند؛ Request user authorization during installation خاموش و Redirect on update روشن باشد. فقط Contents و Metadata فقط‌خواندنی لازم‌اند.

## انتخاب مخزن‌های مجاز
برای برنامهٔ ازقبل‌تنظیم‌شده، روی «ادامه در GitHub» بزنید. هنگام نصب برنامه، Only select repositories را انتخاب و مخزن‌های دلخواه را مشخص کنید. پس از بازگشت و تأیید هویت، دریافت فهرست در صف انجام می‌شود. در صفحهٔ حساب، مخزن‌های قابل استفاده در پنل را انتخاب و دسترسی‌های هر صفحه را ذخیره کنید. مخزن جدید خودکار مجاز نمی‌شود. انتخاب پنل و مجوز نصب GitHub دو کنترل مستقل‌اند.

## پیگیری و بازیابی
تاریخچهٔ حساب شروع دریافت، صفحه‌های API، نتیجه و تغییر دسترسی مخزن‌ها را همراه تاریخ و ساعت نشان می‌دهد. در شکست، «دریافت دوبارهٔ مخزن‌ها» را بزنید. worker صف control باید فعال باشد. فهرست ناقص جای فهرست قبلی ذخیره نمی‌شود. پس از همگام‌سازی موفق، مخزن حذف‌شده از مجوز سرویس در پنل هم غیرفعال می‌شود. مجوز منقضی با refresh token تمدید می‌شود؛ در شکست، اتصال مجدد لازم است.

## قطع اتصال
«قطع دسترسی پنل» انتخاب‌های مخزن را غیرفعال و اعتبارنامهٔ محلی را باطل می‌کند؛ repository، پروژه یا release حذف نمی‌شود. برای حذف مجوز واقعی، «مدیریت مجوز در سرویس» را باز و نصب برنامه را در GitHub حذف یا محدود کنید. اتصال مجدد از صفحهٔ حساب‌های گیت ممکن است.

## محدودیت فعلی
این بخش حساب و فهرست دسترسی مخزن را مدیریت می‌کند. اتصال منبع به پروژه از فرم ZIP، ثبت webhook و فعال‌کردن auto deploy را انجام نمی‌دهد. جریان OAuth با API ساختگی آزموده شده؛ تأیید زنده با GitHub App واقعی همچنان لازم است. توکن، راز برنامه یا پاسخ خام سرویس را در screenshot و گزارش عمومی منتشر نکنید.
