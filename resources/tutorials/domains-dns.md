## نام دامنه
hostname باید canonical و معتبر باشد و روی همان میزبان تکراری نباشد. URL کامل، پورت یا مسیر را در فیلد دامنه ننویسید. domain به Environment مشخص متصل است، نه هر release دلخواه.

## DNS
رکورد A یا AAAA را نزد ارائه‌دهنده DNS بررسی کنید. راه‌انداز بدون credential و مجوز DNS آن را تغییر نمی‌دهد. ذخیره نام دامنه نباید validation_status را خودکار valid کند. داده مشاهده‌شده زمان دارد و ممکن است stale شود.

## Nginx
قالب ساخت‌یافته باید ابتدا با nginx -t بررسی، سپس atomic اعمال و پس از reload از مسیر واقعی probe شود. شکست باید config قبلی را برگرداند. سایت و مسیر پنل protected هستند.

## محدودیت فعلی
ثبت و صف‌گذاری با اعمال config یکسان نیست. executor زنده هنوز بسته است. پورت یا upstream ثبت‌شده به معنی پورت باز و سرویس سالم نیست. .invalid آدرس عمومی و قابل صدور گواهی ACME نیست.
