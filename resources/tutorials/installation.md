## پیش‌نیاز هدف
Ubuntu Server 22.04، 24.04 و 26.04 روی x86_64 هدف آزمون‌اند. پروفایل مرجع ۱ vCPU و ۲GB RAM است؛ این ظرفیت تضمین ساخت پروژه‌های سنگین Node نیست. قبل از نصب از داده و تنظیمات موجود نسخه پشتیبان بگیرید و دسترسی Console ارائه‌دهنده VPS را بررسی کنید.

## فرمان موجود
برای دیدن طرح نصب از checkout مخزن این فرمان واقعی است. طرح تغییر میزبان انجام نمی‌دهد:
```bash
bash installer/bin/rahandaz-install --plan --state-dir /tmp/rahandaz-plan
```

## اعتماد به انتشار
نصب عمومی تک‌دستوری هنوز منتشر نشده است. artifact، manifest و امضا باید با کلید عمومی از پیش مورد اعتماد بررسی شوند. دانلود کلید و artifact از یک منبع بدون ریشه اعتماد کافی نیست. برای رفع خطای دانلود TLS یا بررسی امضای بسته را خاموش نکنید.

## حساب اولیه
مالک وب و کاربر Linux یکی نیستند. bootstrap مالک رمز را در فایل خصوصی می‌نویسد و ورود اول تغییر رمز می‌خواهد. کاربر عملیاتی Linux باید nologin و بدون sudo عمومی باشد. نصب موفق تنها پس از healthcheck واقعی و آزمون VM قابل اتکاست.
