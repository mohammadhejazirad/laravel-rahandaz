## مرز پروژه و محیط
Project منبع و نوع برنامه را تعریف می‌کند. Environment شاخه، runtime، release، دامنه و داده مستقل دارد. production و staging باید مسیر، پورت و credential مستقل داشته باشند؛ تغییر staging نباید داده production را جایگزین کند.

## قابلیت موجود
فهرست و جزئیات پروژه موجود است. مالک و مدیر از «پروژه جدید» حساب گیت، مخزن و شاخه را انتخاب می‌کنند. نتیجه، پروژه، محیط تولید و درخواست استقرار است؛ runtime و کپی کد روی میزبان هنوز اجرا نمی‌شود. برای پروژه موجود، ZIP را از صفحه جزئیات به محیط مجاز بفرستید. پاسخ پذیرفته‌شدن فایل به معنی استخراج یا استقرار موفق نیست.

## ZIP امن
فایل خارج public نگهداری می‌شود و SHA-256 ثابت دارد. مسیر مطلق، ..، symlink، فایل رمزدار و archive بسیار فشرده رد می‌شوند. نام client فقط برچسب است. فایل حاوی .env واقعی یا کلید پنل را برای تست نفرستید.

## شاخه مستقل
انتخاب branch باید با مشاهده provider و SHA کامل همراه شود. نام branch می‌تواند تغییر کند؛ deployment باید commit ثبت‌شده را اجرا کند. Branch observation قدیمی اثبات نسخه تازه repository نیست.
