# امنیت به‌روزرسانی

اولویت: امنیت، حفظ داده، قابلیت بازیابی، قابلیت اطمینان، سازگاری، تجربه کاربر، و سپس سرعت.

- پنل Shell آزاد و فرمان root اجرا نمی‌کند. `panel_executes_update` همیشه false است.
- `ExecutionGate::allowsHostMutation()` برابر false می‌ماند و `RAHANDAZ_EXECUTION_MODE` برابر `disabled` است.
- حساب `rahandaz` sudo و `NOPASSWD: ALL` نمی‌گیرد.
- ورودی نسخه و مسیرها اعتبارسنجی می‌شوند و به Shell تزریق آزاد نمی‌شوند.
- امضای RSA باید بایت داخل امضا را رد کند. چسباندن بایت به انتهای امضای معتبر هنوز verify می‌شود، پس آزمون باید بایت میانی را برگرداند.
- checksum ناسازگار فقط وقتی نام فایل با نام داخل manifest یکی است فایل را حذف می‌کند.
- قفل فایل از اجرای هم‌زمان جلوگیری می‌کند. آزمون باید فرزند `flock` را هم ببندد.
- Mirror دانلود را عوض نمی‌کند مگر manifest، امضا و digest همان artifact حفظ شود. metadata غیرقابل اعتماد به‌روزرسانی را شروع نمی‌کند.
- اگر GitHub و mirror معتبر هر دو نباشند، پنل بالا می‌ماند، نسخه نصب عوض نمی‌شود، و خطا قابل تکرار است.
- Login درخواست GitHub نمی‌زند. بررسی زمان‌بندی‌شده timeout کوتاه، دو retry، ETag و قفل ۵۵ ثانیه‌ای دارد.
- Secret در argv، لاگ و props اینرسی نمی‌آید. پشتیبان کلید حالت `0600` دارد.
- به‌روزرسانی عادی کلید رمزنگاری را دوباره نمی‌سازد.
