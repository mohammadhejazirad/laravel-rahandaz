# واژه‌های محصول

| مفهوم | واژه |
| --- | --- |
| محصول | راه‌انداز، و به انگلیسی Rahandaz |
| معرفی | اسکریپت راه‌انداز یا سامانه راه‌انداز، متناسب با جمله |
| رابط مدیریت | پنل مدیریت راه‌انداز |
| نصب | نصب‌کننده راه‌انداز |
| به‌روزرسانی | سیستم به‌روزرسانی راه‌انداز |
| عملیات میزبان | موتور عملیات سرور |
| کاربران، سرور، پروژه‌ها | مدیریت کاربران، مدیریت سرور، مدیریت پروژه‌ها |

شعار رابط «پنل مدیریت سرور محلی» است. واژه‌های قبلی «کنترل‌پنل» و «کنترل‌پلین» در متن نمایشی و مستندات محصول جایگزین شده‌اند.

جایگزینی شناسه فنی، نام جدول، نام کلاس، migration و اصطلاح انگلیسی معتبر مثل `execution plan` انجام نشده است. مقدار `execution_mode` همان رشته `disabled` می‌ماند.

view کامپایل‌شده زیر `storage/framework/views` منبع نیست و ویرایش نشده است. assetهای `public/branding` و `assets/branding/og-image.svg` شعار را در متن SVG دارند. PNGهای از قبل ساخته‌شده دوباره رسم نشده‌اند.
