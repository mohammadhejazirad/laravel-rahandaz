# عملکرد رابط و بودجهٔ اندازه‌گیری

## نتیجهٔ build رابط — ۲۰۲۶-۱۰-۱۶

اندازه‌های گزارش‌شده توسط Vite build محلی، با dependencyهای موجود و بدون پکیج تازه:

- CSS پیش از بازچینی ۷۳٫۹۰ کیلوبایت و ۱۳٫۱۵ gzip بود؛ پس از بازچینی ۷۰٫۹۰ و ۱۲٫۹۸ است.
- chunk پوستهٔ اصلی از ۶۷٫۴۸/۲۲٫۰۸ gzip به ۷۱٫۸۱/۲۳٫۸۷ رسید؛ جست‌وجوی سریع و metadata مشترک ناوبری به آن اضافه شدند. بنابراین کاهش اندازهٔ تمام JavaScript ادعا نمی‌شود.
- chunk داشبورد ۷٫۹۱/۲٫۶۴ gzip است؛ پروژه‌ها و عملیات واقعی اخیر و مسیر شروع را نشان می‌دهد.
- بزرگ‌ترین shared chunk همان ۳۷۳٫۸۸/۱۱۶٫۶۸ gzip باقی است. فایل فونت محلی ۱۱۱٫۱۵ کیلوبایت است.
- زمان build گزارش‌شده حدود ۷۵۳ میلی‌ثانیه بود؛ این عدد زمان بارگذاری صفحه یا benchmark سرور نیست.

اعداد snapshot همان اجرای build هستند و با تغییر bundling ممکن است جابه‌جا شوند. measurement شبکه، زمان تعامل، RAM مرورگر و Web Vitals انجام نشده‌اند.

## اقدام‌های انجام‌شده

تزئین fixed تمام صفحه و backdrop blur نوار اصلی حذف شدند. جدول semantic فقط یک نسخه از ردیف‌ها دارد و با CSS در موبایل به کارت تبدیل می‌شود. اسکریپت جست‌وجوی بخش‌ها شبکه نمی‌خواند. صفحه‌ها همچنان با import پویا جدا هستند. فرم جمع‌شونده و بخش‌های درون‌صفحه‌ای درخواست تازه ایجاد نمی‌کنند.

polling در صفحهٔ پنهان/آفلاین توقف و درخواست جاری را لغو می‌کند، هم‌پوشانی نمی‌سازد و در شکست شبکه/HTTP با backoff تا ۱۲۰ ثانیه ادامه می‌دهد. Job پایانی polling ندارد؛ Git و پایش قرارداد دوره‌ای مستقل دارند. این تغییر مقدار CPU یا نرخ خطای production را اندازه نگرفته است.

داشبورد حداکثر شش پروژه و شش Job اخیر با allowlist props می‌خواند؛ شمار محیط با withCount است. فیلترهای پروژه و عملیات روی query Workspace اعمال و paginate می‌شوند. جست‌وجوی نام literal است؛ index جست‌وجوی dataset بزرگ و EXPLAIN هنوز انجام نشده‌اند.

## آزمون لازم پیش از پذیرش عملکرد

با دیتاست واقعی و مجوزهای نماینده، TTFB/p95، query count، payload انتقال، تعامل فرم و refresh لاگ اندازه‌گیری شود. شبکهٔ کند/قطع، ۳۰ دقیقه idle و tab پنهان، خطای HTTP و مصرف حافظهٔ مرورگر بررسی شوند. هفت عرض و دو تم با ردیف‌های طولانی و صفحه‌بندی آزموده شوند. آزمایش رندر محلی HTML فقط ساختار و escaping را می‌سنجد.

بودجهٔ مرجع میزبان ۱ vCPU و ۲GB RAM و هدف footprint در `.docs/PROJECT_SPEC.md` آمده است. آزمون منابع control plane و deployment در Ubuntuهای 22.04/24.04/26.04 با systemd و workload واقعی همچنان نیازمند VM است. این بازچینی تغییری در installer، helper یا اجرای میزبان ایجاد نمی‌کند و گواهی Matrix یا production-ready نیست.
