# Framework marks

Monochrome paths are from Simple Icons 15.15.0:
https://github.com/simple-icons/simple-icons/tree/15.15.0/icons

Files: php, laravel, node (`nodedotjs`), nuxt, next (`nextdotjs`), vue (`vuedotjs`), react, adonis (`adonisjs`), express, nest (`nestjs`), html5, python, django, flask, fastapi, wordpress.

Simple Icons distributes these paths under CC0-1.0:
https://github.com/simple-icons/simple-icons/blob/15.15.0/LICENSE.md

`FrameworkIcon` paints them with `currentColor`, so light theme stays black and dark theme stays white. These are application marks, not Rahandaz branding assets.
