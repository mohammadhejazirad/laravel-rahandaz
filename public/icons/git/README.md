# Provider icons

GitHub and GitLab SVG paths are from Simple Icons:
https://github.com/simple-icons/simple-icons/tree/develop/icons

Source files: github.svg and gitlab.svg. Simple Icons distributes icon paths under CC0-1.0:
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Rendered locally in GitProviderIcon with currentColor for light/dark themes. Self-managed GitLab combines the GitLab mark with the existing Lucide Server indicator. These are provider marks, not Rahandaz branding assets.
